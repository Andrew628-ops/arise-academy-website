# Arise Academy — Website Prototype

This repository contains a responsive, modern primary school website prototype for "Arise Academy" built with HTML, CSS, and JavaScript.

Features:
- Home, About, Academics, Admissions, Our School, News & Events, Contact pages
- Responsive navigation with hamburger menu
- Hero, cards, statistics, principal's message, testimonials carousel, news, gallery
- Online application and contact forms configured for Formspree (replace endpoint)
- AOS scroll reveal animations
- Unsplash placeholder images (replace with your own images)

Deployment:
- Recommended: Deploy to Vercel. Link the repository and Vercel will build and publish the static site automatically.

Formspree:
- Replace the placeholder action URLs (https://formspree.io/f/YOUR_FORMSPREE_ENDPOINT) with your Formspree form endpoint so forms submit correctly.

Customize:
- Change content in the HTML files under the repository root.
- Images use Unsplash URLs; replace with local files in assets/images and update paths if preferred.
- CSS is in assets/css/style.css
- JS is in assets/js/main.js

Unsplash Attribution:
Images are used from Unsplash as placeholders. Replace them with your own images for production.
